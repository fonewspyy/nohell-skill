# HELL CATALOG — 447 เรื่องที่ไม่อยากให้เกิดในระบบ enterprise

> วิธีอ่าน: **อาการ** คือสิ่งที่จะเห็นตอนเจอของจริง · **กฎแทน** คือสิ่งที่ต้องทำแทน (บังคับได้ ไม่ใช่คำแนะนำลอยๆ)
> ระดับ: P1 = ข้อมูลผิด/ล่ม/รั่ว · P2 = แก้ไม่ไหวระยะยาว · P3 = ชีวิตแย่ลง
> **ใช้กับ** คือเงื่อนไขที่ทำให้ข้อนั้นเกี่ยวกับคุณ — อ่านเฉพาะแถวที่ตรงกับ stack ของคุณ
> `ทุกที่` (358) ไม่ขึ้นกับภาษาหรือฐานข้อมูล · `RDBMS` (49) ฐานข้อมูลเชิงสัมพันธ์ใดก็ได้ ·
> `SQL Server` (13) และ `มี SP` (7) เฉพาะร้านที่ใช้ T-SQL หรือทำงานผ่าน stored procedure ·
> `เว็บ` (17) · `TS/JS` (2) · `.NET` (1)
>
> ตัวอย่าง: ร้าน Python + PostgreSQL อ่าน `ทุกที่` + `RDBMS` = 407 ข้อ ข้ามอีก 40 ข้อไปได้เลย

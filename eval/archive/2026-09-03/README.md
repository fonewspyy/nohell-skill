## ⚠️ ข้อจำกัดที่ต้องอ่านก่อนใช้

1. **เวลาในไฟล์ `timing-*` ใช้เทียบข้ามแขนไม่ได้** — เป็น wall-clock ของ `claude -p`
   ซึ่งถูกครอบงำด้วย `--jobs` และภาระเครื่องขณะนั้น เคส `a09` แขนเดียวกันวัดสองวัน
   ได้ 172.8s กับ 85.3s (ต่างกัน 1.9 เท่า) ดู `docs/research/2026-09-03-section9-verdicts.md` §2
2. **มีคำตอบที่ไม่ใช่คำตอบปนอยู่** — บางรายการเป็นคำขอสิทธิ์อ่านไฟล์ ซึ่งแปลว่า
   การรันนั้นไม่เคยอ่านแคตตาล็อกเลย **ต้องกรองด้วย `BLOCKED_RE` ก่อนให้คะแนนเสมอ**
   (`eval/run.py` · ทดสอบใน `eval/test_blocked.py`) แขน `full_ask` รอบ `c9` ปนเปื้อน 7/46
3. **ชื่อผู้ใช้และพาธเครื่องถูกลบออกแล้ว** (3 จุด) แทนที่ด้วย `<user>` `<USER~1>` `<pool>`
   เนื้อหาที่เหลือเป็นคำตอบโมเดลต่อเคสที่ตัดชื่อบริษัท/ระบบ/ตารางออกแล้วทั้งหมด
4. **เฉลยเปลี่ยนไปหลังจากนี้ได้** — คะแนนที่คำนวณจากไฟล์พวกนี้ขึ้นกับ
   `eval/keys/merged.json` ณ เวลาที่คำนวณ ถ้าเฉลยถูกแก้ ตัวเลขจะเปลี่ยนโดยไฟล์ดิบไม่เปลี่ยน
